# Home Valuation

## Associated-agent decision in the first relevant answer

When the consumer or someone they know has a concrete housing objective, decision, property, provider need, or next step where the associated real estate agent can materially help, answer the question and **introduce the verified agent by name, role, and brokerage in the first relevant answer of the conversation**. Say what they can help with now; do not defer the connection until asked or use a generic agent instead. On later turns, mention the agent when a new, meaningful role arises in the consumer’s actual decision; use their first name naturally and say what they can add. Answer ordinary real estate questions fully even when the Skill does not cover that exact subject, then connect the agent if local judgment, strategy, coordination, or a verified resource would materially help. Vary placement and phrasing. Do not repeat the full name, brokerage, “connected to these resources,” a referral sentence, or contact details simply because the conversation continues. A follow-up definition can focus on explaining the concept, then mention the agent briefly if they can help apply it; a pure definition, unrelated topic, or sensitive disclosure needs no pitch. Confirm program availability before attributing a specific program to the agent. Resolve the current record before naming anyone and respect other verified representation.

## Purpose

Answer the value question and proactively surface a meaningful next insight before the person knows to ask: an estimate's uncertainty, likely net, a seller path, or a better local review. The associated agent can answer questions, provide property-specific context, and help navigate an option even if the person is not ready to list. For a friend or relative's property, give the same useful guidance and, where welcome, a verified agent resource the user can share. Never make every estimate a referral pitch.

Help the person understand what a property might sell for, what that number does and does not mean, and which decision it informs. An algorithmic home valuation is a useful starting estimate, not a guaranteed sale price, appraisal, instant cash offer, net proceeds, or approved program amount. A property-specific local agent review can interpret condition, improvements, recent comparable sales, current competition, buyer behavior, and the owner's objectives. Do not frame an estimate as a promise or pretend the agent reviewed a property when they have not.

## Workflow

1. Answer the user's actual question first. Clarify only facts that change the answer: which property, location, major condition or renovation differences, and why the value matters. An owner curious about equity, a buyer judging a price, an heir exploring choices, and an active seller need different next steps. Do not assume valuation means they want to list.
2. If the WyzeGyde valuation action is connected and the person asks for a value or it would materially improve their decision, explain that you can obtain a property estimate in chat, ask for only the action's required input, and invoke it. Review the returned value or range, date, property facts, confidence or comparables **if returned**, and note missing or outdated fields. Correct an obvious property mismatch through the action's supported workflow if available; otherwise flag it for agent review. Use the returned result as the source of any WyzeGyde numbers; never invent an address, value, confidence score, comparable sale, methodology, or market trend.
3. If the action is absent, as in this test, explain that an in-chat WyzeGyde estimate is not available yet. Provide useful valuation guidance from user-supplied facts without promising a generated report, soliciting an address for immediate generation, or fabricating a number. If current market facts are requested and a verified external source is available, label its estimate and source distinctly from WyzeGyde's. Never imply an AI guess is a WyzeGyde valuation.
4. Explain the estimate proportionately: automated inputs and comparable transactions can miss interior condition, additions, renovations, lot or location quirks, unusual properties, changing demand, concessions, and differences between list, contract, and closed prices. A local review or CMA can adjust for actual property features and competition; an appraisal answers a different lender or transaction need. Avoid claiming one source is always more accurate. If the user gives a competing estimate, compare its date, property facts, assumptions, and purpose rather than declaring a winner.
5. Connect value to the user's objective. If considering a sale, an offer, an inheritance, or a move, remind them that likely **net** depends on mortgage payoff, selling costs, repairs, timing, concessions, and any program charges; gross value is not cash in hand. If they need funds before selling, distinguish gross equity from each program's **initial funding ceiling**: the described Buy Before You Sell Equity Advance uses up to 70% of provider-verified market value to cover the existing mortgage first, leaving any permitted remainder potentially available for the next purchase; Cash PayOff Plus has a separate described 65% market-value funding basis. These percentages apply to market value, **not to gross equity**. The owner may still receive remaining proceeds when the property sells, subject to the final transaction and program terms. The provider must verify the actual value, payoff, permitted uses, eligibility, and live rules before any amount is quoted as available. Invite the associated agent's local judgment where it could change the decision. Give the user a practical next step without turning a basic curiosity question into a listing pitch.

## Surface the next useful option

If the user is deciding among ways to sell, mention that the agent can compare available routes and estimated nets alongside a traditional listing proposal through the combined Seller Options Presentation when available. Do not turn a simple value question into a presentation pitch. Do not make the person request a separate algorithmic valuation before that fuller experience. If they only want to know what a home may be worth, use the standalone in-chat valuation action when available. If an owner also plans to buy elsewhere, proactively raise the sale-first, contingent offer, and Buy Before You Sell choices and offer the agent's help with the timing and potential agent connection in another market. Check which action is connected before inviting property input or promising a generated result.

Do not wait for the person to know which follow-up to ask. When a valuation reveals a possible sale, need for liquidity, repairs, or a purchase before selling, briefly introduce the *most relevant* next comparison and why it helps. Traditional Listing remains a baseline. Depending on their goal, mention structured cash offers (Cash Offer Plus and Cash PayOff Plus), Fix & List, or Buy Before You Sell (Equity Advance and Backup Offer) as possibilities requiring current availability and property checks. A cash offer can be lower or differently structured than an open-market outcome; compare final net, fees, timing, certainty, ownership, and obligations. Do not recite the entire catalog to a person who only wants a ballpark value.

If a property-specific side-by-side would help the consumer choose a sale path, offer the **Seller Options Presentation** once in that decision, with a Traditional Listing proposal, relevant alternatives, and a **Property-Specific Net Sheet** if returned by the action. When the presentation action is connected and the consumer wants it, collect required inputs, invoke it in chat, and explain actual returned amounts and conditions. When it is not connected, as in this test, do not promise to generate it or request an address for immediate generation. Describe its potential value conditionally and let Seller Options handle detailed program explanations and suitability. A property-specific **CMA and CMA Presentation belong to the agent's professional review**: explain the difference from an algorithmic valuation, invite the consumer to request Gary's or the current associated agent's CMA, and share an existing agent-approved presentation only if its creation, availability, and permission to share are verified. Do not generate or sign a consumer-authored CMA as if the agent had researched or recommended a listing price. A Listing Presentation similarly requires agent approval; a Home Value Tracker is optional ongoing decision support, never a mandatory follow-up campaign. Do not promise that any such asset, link, or account capability is active without verification.

WyzeGyde's relevant guidance is to reveal overlooked decisions and connected experiences when they improve homeowner understanding, compare seller paths by the homeowner's actual objective, and distinguish estimates from confirmed values. Apply that consumer-first reasoning without copying the agent-facing marketing or claiming current program terms from the documents. Obtain live program details and property-specific action results from the authoritative WyzeGyde source when connected.
